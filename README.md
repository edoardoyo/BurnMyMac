# BurnMyMac

菜单栏一键开关：阻止 Mac **系统 idle 休眠**，允许屏保和显示器关闭。适合整晚跑 Codex、脚本或长时间后台任务。

## 使用

1. 构建应用：

   ```bash
   ./scripts/build.sh
   ```

2. 打开应用：

   ```bash
   open build/BurnMyMac.app
   ```

   或把 `build/BurnMyMac.app` 拖到「应用程序」文件夹。

3. 菜单栏出现 🔥 图标：
   - **左键单击**：切换保持唤醒（亮起 = 开启）
   - **右键单击**：菜单（切换 / 使用指南 / 退出）

4. **使用指南**：右键菜单 →「使用指南…」，查看锁屏、睡眠等场景说明。

## 行为说明

- **开启**：系统不会因 idle 自动休眠，后台程序和网络保持可用
- **关闭 / 退出**：立即释放防休眠，恢复系统默认节能
- **允许**：屏保、显示器自动关闭
- **不阻止**：手动睡眠、合盖睡眠、低电量强制睡眠

## 特点

- 无 Dock 图标，仅菜单栏常驻
- 不写配置文件、不建缓存，删除 App 即卸载干净
- 体积小，空闲时几乎不占 CPU

## 要求

- macOS 13.0 或更高

## 开发

```bash
./scripts/build.sh
```

产物位于 `build/BurnMyMac.app`。
